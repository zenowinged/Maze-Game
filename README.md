# Adaptive Maze Game 🧩

## Overview
A tricky, interactive browser-based maze game where not everything is as it looks. The "adaptive" nature of the maze challenges players as they progress, relying on dynamic grid-based movement logic, state management, and real-time UI rendering on the frontend. 

## Features
* **Dynamic Grid Rendering:** The maze layout and DOM update dynamically based on player state and actions.
* **Keyboard Input Handling:** Smooth player movement using event listeners for directional controls.
* **Collision Detection:** Core game logic to prevent movement through walls and boundaries.
* **Win Condition States:** Real-time tracking of player position against the maze exit.

## Tech Stack
* **JavaScript (Vanilla):** Core game logic, DOM manipulation, state management, and collision detection.
* **HTML5 & CSS3:** Game canvas structuring and visual styling.
* **Python:** *(Used for backend logic/generation where applicable).*
* **Vercel:** Continuous deployment and live hosting.

## Technical Learnings
Building this game served as a hands-on exercise in translating complex logical constraints into a visual user experience. It heavily involved structuring game loops, handling asynchronous user inputs, and managing browser states efficiently without relying on heavy external game engines.
